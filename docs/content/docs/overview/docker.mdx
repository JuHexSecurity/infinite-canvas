# Docker Deployment

## Use the published image

```bash
git clone https://github.com/JuHexSecurity/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

Open `http://localhost:3000`.

## Build locally

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## Documentation image

The documentation in `docs/` is a separate Next.js standalone application with server capabilities.

```bash
cd docs
docker compose up -d
```

To build it from the current source:

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

The main application container serves the frontend and can optionally start the private AI gateway. Canvases, My Assets, and generation history are stored in the browser by default, while prompt repositories are fetched directly by the frontend. No persistent data volume is required for this data.

## Private AI gateway

For team deployments, set `PRIVATE_DEPLOYMENT=true`. Set `AI_ALLOW_CLIENT_KEYS=true` for an internal deployment where each user may enter a provider key in the browser; the key stays in that user’s browser storage and requests still pass through the same-origin gateway. Set it to `false` to use only `AI_UPSTREAM_API_KEY` from the server environment and hide the browser key field. The gateway only forwards `/v1` and `/v1beta` paths; put authentication or an internal-network restriction in front of it before exposing the deployment.

## Optional analytics

No analytics are enabled by default. A deployment can enable GA4, Baidu Analytics, or both at runtime:

| Variable | Description |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 measurement ID (`G-XXXX`) |
| `ANALYTICS_BAIDU_ID` | Baidu site ID, the hash after `hm.js?` |

```yaml
services:
  app:
    image: ghcr.io/juhexsecurity/infinite-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

SPA route changes automatically report page views to enabled providers. Only configure analytics IDs on sites you control, and do not commit them to the repository.
